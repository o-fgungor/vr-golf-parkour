# VR Golf Parkour

A VR locomotion study built in Unity for Meta Quest. The player navigates a parkour course by hitting a golf ball with a physical club, when the ball stops, they teleport to its position. The goal is to complete the course while collecting coins and interacting with objects along the way.

## Mechanics

- **Golf locomotion** — hit the ball, teleport to where it lands
- **Two ball modes** — white ball teleports, red ball doesn't (toggleable with left stick click)
- **Parkour stages** — 3 stages with banners, coins, and object interaction tasks
- **Data recording** — completion times per stage are tracked

## Built With

- Unity (Meta XR SDK / OVR)
